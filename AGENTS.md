# Base Completa — regras de agentes

- Para prévias da Central na Vercel, siga `docs/PREVIEW_ACCESS.md`.
- Gere sempre um link de **Prévia sem login** para o proprietário quando possível.
  A chave está somente no ambiente **Preview** do projeto Vercel.
- Nunca copie o token de acesso para repositório, relatórios, PRs ou produção.
- Nunca implemente bypass genérico de login na produção e não use dados de
  alunos para demonstração. O convidado fictício não pode acessar APIs de dados.
- Modificações visuais ou jurídicas devem ficar em branch de teste até
  autorização explícita para publicar.
