# Artes da Revisão Guiada — Direito Constitucional M12

O mapa de capítulos acompanha `content/cf/m12-teoria-guiada-data.js` e preserva os treze títulos originais. O renderer reaproveita o template SVG programático e os recursos originais de logo e personagem do padrão aprovado. Cada arte tem quatro pictogramas vetoriais distintos, escolhidos para os conceitos do capítulo.

## Gerar

```sh
python3 artes/cf-m12/render.py
```

Gera PNGs de 1229 × 1536 em `artes/cf-m12/png/` e WebPs otimizados para a aplicação em `assets/cf/revisao-guiada/m12/`.
